Supported conversions

The converter covers metric and US customary units for distance, weight and mass, area, volume, speed, plus Celsius, Fahrenheit, and Kelvin temperatures.

How conversion factors work

Converted value = original value × source factor ÷ destination factor

Most categories use a shared base unit. Temperature uses separate formulas because its scales have different zero points as well as different interval sizes.

Precision

Results display up to four decimal places. The internal factors retain more precision, but a rounded display should not be treated as more precise than the original measurement.
