How to use the result

The monthly amount is an estimate based on steady monthly deposits and a constant annual return. If the required contribution is too high, compare the effect of extending the timeline, lowering the goal, or starting with more saved.

Planning with uncertain returns

Try a conservative return and a zero-return scenario. A savings account, investment account, and short-term cash goal have different risks and expected returns, so one assumption does not fit every goal.

Good inputs produce useful estimates

  • Use the amount already dedicated to this specific goal.
  • Express the timeline in years, including partial years.
  • Do not treat an assumed return as guaranteed.
